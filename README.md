# WitAnime CloudStream Repository

WitAnime provider repository for CloudStream 3 by ahmedessameldeen-code.

## Installation

1. Open **CloudStream 3** on your Android TV or phone.
2. Go to **Settings (`⚙️`) ➜ Extensions ➜ Add Repository**.
3. Paste the repository link:
```text
https://raw.githubusercontent.com/ahmedessameldeen-code/witanime-cloudstream-repo/builds/repo.json
```
4. Click **Download**, select **WitAnime Pro**, and click **Install**.
